## Quick start

```bash
git clone https://github.com/AbdullahBakir97/Baeckrei.git
cd Baeckrei
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
